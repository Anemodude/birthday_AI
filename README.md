AI Birthday Celebration 
A fun AI-powered birthday celebration application built with Python to Celebrate my Birthday.

Features
Real-time webcam integration using OpenCV
Hand tracking with MediaPipe
Voice recognition using SpeechRecognition
Birthday music playback with Pygame
Animated balloons
Personalized birthday celebration screen
Camera snapshot displayed during celebration
How It Works
Launch the application.

Allow camera and microphone access.

Say:

Joseph

The application automatically:

Plays birthday music
Displays balloons
Captures a live camera snapshot
Shows a personalized birthday message
Technologies Used
Python
OpenCV
MediaPipe
SpeechRecognition
PyAudio
Pygame
